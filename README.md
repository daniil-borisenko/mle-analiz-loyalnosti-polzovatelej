# MLE: Анализ лояльности пользователей Яндекс Афиши

## Описание проекта

Проект посвящён анализу поведения пользователей сервиса «Яндекс Афиша» для выявления факторов, связанных с повторными покупками.

В рамках проекта реализован пайплайн:

1. **Загрузка и подготовка данных** — получение данных из базы данных, загрузка курсов валют и конвертация выручки из тенге в рубли.
2. **Очистка данных** — обработка отрицательной выручки, дубликатов и выбросов.
3. **Профилирование пользователей** — расчёт количества заказов, средней выручки, среднего интервала между заказами и признака повторной покупки.
4. **Анализ лояльности** — расчёт Retention в зависимости от типа первого мероприятия, устройства и региона.
5. **Корреляционный анализ** — оценка связи характеристик пользователей с количеством заказов с помощью коэффициента Phi-K.

## Как запустить

1. Клонировать репозиторий

```
git clone <ссылка-на-репозиторий>
cd <название-папки>
```

2. Создать виртуальное окружение
```
python3 -m venv venv
```

3. Активировать виртуальное окружение

- Для Windows:
```
venv\Scripts\activate
```

- Для Linux/macOS:
```
source venv/bin/activate
```

4. Установить зависимости
```
pip install -r requirements.txt
```

5. Настроить подключение к базе данных
Создать в корне проекта файл .env:
```
DB_USER=ваш_логин
DB_PWD=ваш_пароль
DB_HOST=адрес_сервера
DB_PORT=порт
DB_NAME=название_базы
```

6. Добавить файл с курсами валют
Поместить файл final_tickets_tenge_df.csv в директорию data/

7. Запустить проект
```
python3 main.py
```

## Основные результаты анализа

В результате анализа пользовательской активности были получены следующие результаты:

- В выборке около 20,6 тыс. пользователей.

- Около 59,6% пользователей совершили два и более заказа.

- Наиболее заметная связь с количеством заказов наблюдается у среднего интервала между заказами.

- Связь количества заказов с устройством, типом первого мероприятия и регионом оказалась слабой.

- Проверка гипотез не выявила выраженной зависимости Retention от типа первого мероприятия и активности региона.

- День недели первой покупки также не показал существенного влияния на повторные покупки.

## Рекомендации

На основании проведённого анализа можно выделить следующие направления для дальнейшей работы:

- учитывать интервалы между заказами при анализе поведения и удержания пользователей;

- не ограничиваться устройством, регионом или типом первого мероприятия при поиске факторов лояльности;

- дополнительно исследовать поведение пользователей во времени;

- расширить анализ за счёт других характеристик пользователей и их заказов, которые могут быть связаны с повторными покупками.

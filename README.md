# MLE: Анализ лояльности пользователей Яндекс Афиши

## Описание проекта

Проект посвящен анализу поведения пользователей сервиса «Яндекс Афиша» для выявления факторов лояльности и формирования рекомендаций по удержанию клиентов.

В рамках проекта реализован полный пайплайн обработки данных:
1.  **Загрузка и очистка:** Обработка сырых данных о заказах, конвертация валют (тенге → рубли), удаление аномалий и выбросов.
2.  **Детекция ботов:** Фильтрация технических аккаунтов и подозрительной активности на основе метрик интенсивности заказов, географического разброса и частоты действий.
3.  **Профилирование пользователей:** Построение индивидуальных профилей пользователей с расчетом ключевых метрик (средний чек, частота заказов, доля вернувшихся).
4.  **Аналитика:** Расчет Retention по когортам, проверка статистических гипотез и корреляционный анализ.

**Основной стек технологий:** Python, Pandas, NumPy, Matplotlib, Seaborn, Phi-K, SciPy, Statsmodels.

## Как запустить проект
1. Клонируйте репозиторий и перейдите в папку
2. Создайте и активируйте виртуальное окружение
3. Установите зависимости
4. Настройте доступы к базе данных
5. Положите файл с курсами валют в папку data/
6. Запустите пайплайн
